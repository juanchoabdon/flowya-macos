# Object Sans Font

Place your Object Sans font files here.

## Required files (any format works):

**Regular (400):**
- `ObjectSans-Regular.woff2` (preferred)
- `ObjectSans-Regular.woff`
- `ObjectSans-Regular.otf`

**Medium (500):**
- `ObjectSans-Medium.woff2`
- `ObjectSans-Medium.woff`
- `ObjectSans-Medium.otf`

**Bold (700):**
- `ObjectSans-Bold.woff2`
- `ObjectSans-Bold.woff`
- `ObjectSans-Bold.otf`

**Heavy (800):** *(optional)*
- `ObjectSans-Heavy.woff2`
- `ObjectSans-Heavy.woff`
- `ObjectSans-Heavy.otf`

## Notes:
- `.woff2` is the most efficient format
- The app will fall back to system fonts if Object Sans is not available
- You only need ONE format per weight (woff2 recommended)
